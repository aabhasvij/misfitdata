Appendix — Detailed Task Plan

Cashflow transformer & concept score development

Step-by-step task breakdown from raw transaction collection through concept-score training, including the feature-grouping encoder design and the optional fusion embedding.

1

Collect raw cashflow transaction data

Assemble the source transaction stream at the consumer level.

2

Create performance flags and cashflow filters

Define target performance flags and the transaction filters (e.g. regular income, card expense) used downstream.

3

Decide aggregation time step and observation window

Weekly — 12 weeks
Biweekly — 24 weeks
Monthly — 12 months
4

Aggregate cashflow data by time step using predefined filters

Produce time-stepped feature matrices. Example feature names:

regular_income_biweekly_5 card_expense_monthly_3
5

Apply scaling and padding

Normalize feature values and pad sequences to a consistent shape for the encoder.

6

Perform feature grouping

Assign aggregated features to concept groups.
Train one Transformer encoder per feature group.
Extract the group CLS embedding from each encoder.
7

Train a fusion CLS embeddingOptional

Use the group embeddings to train a combined fusion CLS embedding across all groups.

8

Create AAC labels for each sample

Derive adverse-action-consistent labels from an XGBoost model built on cashflow attributes.

9

Train cashflow risk concept scores

Train concept scores using the group CLS embeddings.

Optionally include the fusion CLS embedding as an additional input.
